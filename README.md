# ChaloChale Travel App — Responsive Lab Final

This project follows the supplied ChaloChale lab instructions and the additional screenshots.

## Pages
- index.html — Home
- destinations.html — Destinations
- packages.html — Packages
- booking.html — Travel Booking Form
- contact.html — Contact
- signup.html — Signup
- login.html — Login

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Font Awesome

## Responsive layout
The main content intentionally uses the available browser width:
- Mobile: 1 column
- Tablet: 2 columns
- Desktop: 3 columns

Bootstrap utilities used include:
`container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `py-*`, `mb-*`, `p-*`, `rounded-*`, `shadow-lg`, and `w-100`.

## Windsurf lab activity
Suggested prompt from the lab:
"Improve this Bootstrap cards section and make it more responsive."

The responsive/UI improvements described in the lab have been incorporated into the final implementation.

## Run
Open `index.html` in a browser. An internet connection is required for Bootstrap, Font Awesome, and Unsplash images.
